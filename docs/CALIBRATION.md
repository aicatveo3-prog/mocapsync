# 캘리브레이션 촬영 가이드

캘리브레이션은 두 가지입니다. 둘 다 앱으로 **영상**을 찍습니다 (사진 모드 금지 — 형식이 달라집니다).

| | 무엇 | 언제 | 명령 |
| --- | --- | --- | --- |
| ① 렌즈 특성 | 렌즈가 화면을 얼마나 휘게 찍는지 | **폰마다 한 번** (렌즈·해상도·fps 를 바꾸면 다시) | `intrinsics` |
| ② 위치·방향 | 폰들이 어디서 어느 쪽을 보는지 | **폰을 놓을 때마다** (삼각대를 건드리면 다시) | `extrinsics` |

①이 끝나야 ②를 할 수 있습니다. ②가 끝나면 `~/Pose2SimWork/rig/` 에 리그가 생기고,
그 뒤로 찍는 촬영은 3D 까지 나옵니다.

---

## 0. 준비 (한 번)

1. 바탕화면 `MocapSync_checkerboard_A4_7x10_23mm.pdf` 를 **"실제 크기"** 로 인쇄합니다 ("페이지에 맞춤" 아님).
2. 종이 아래 **100 mm 막대를 자로 잽니다.**
   - 100 mm 면 그대로 씁니다 (한 칸 23 mm).
   - 다르면 한 칸 크기 = 23 × (잰 길이 ÷ 100) 입니다. 예: 98 mm → 22.54.
     명령 끝에 `--square-mm 22.54` 를 붙입니다.
3. 종이를 **딱딱하고 평평한 판**(하드보드, 폼보드, 두꺼운 책 표지)에 붙입니다. 울면 안 됩니다.
4. 방을 **밝게** 합니다. 녹화 화면의 ISO 경고가 뜨지 않을 만큼.

---

## ① 렌즈 특성 (폰마다 한 번)

**찍기** (폰 한 대당 1~1.5분)

1. 폰을 삼각대나 책상에 **가로로** 세우고 앱에서 "PC 원격 대기 켜기".
   두 폰을 같이 켜 두고 한 번에 찍어도 됩니다 (한 폰 앞에서 1분, 다른 폰 앞에서 1분).
2. 대시보드에서 **녹화 시작**.
3. 판을 폰에서 **30~80 cm** 에 듭니다. 판이 화면 폭의 1/4~1/2 정도로 보이면 알맞습니다.
4. 판을 화면의 **9곳**(가운데, 네 모서리, 네 변 가운데)으로 옮겨 갑니다. 자리마다
   판을 위·아래·왼쪽·오른쪽으로 **30~45도 기울여** 3~4 자세를 보여 줍니다.
   - ★ **자세마다 1초씩 멈추세요.** 움직이는 판은 흔들리고 기울어져 찍혀서(롤링셔터) 도구가 버립니다.
   - ★ **구석까지** 가져가세요. 초광각은 가장자리가 가장 많이 휩니다. 단, 판이 화면 밖으로 잘리면 그 장면은 못 씁니다.
5. 녹화 정지 → 업로드가 끝날 때까지 기다립니다.

**계산**

```powershell
& "$env:USERPROFILE\.venv\pose2sim_gpu\Scripts\python.exe" tools\calibrate.py intrinsics <세션이름>
```

**이렇게 보이면 성공** (폰마다)

- `재투영 오차 0.xxx px` 가 **0.5 이하**
- `화면 덮은 비율` **70% 이상**, `가장자리` **60% 이상**
- `계산한 가로 화각` 이 폰이 알려준 값(초광각 107.8도)과 몇 도 안쪽
- `판정: 좋음`, `저장: ...\intrinsics\<기기ID>.json`
- 확인 그림 `~/Pose2SimWork/intrinsics/<기기ID>_coverage.jpg`: 초록 점이 화면 곳곳에, **빨간 칸이 거의 없음**

**안 되면**

| 보이는 말 | 할 일 |
| --- | --- |
| `판이 한 번도 보이지 않았습니다` | 판 전체가 화면에 들어왔는지, 조명, `--board` 설정 |
| `빠르다고 뺀 장면` 이 대부분 | 더 천천히, 자세마다 1초 멈춤 |
| `화면의 xx% 에만 닿았습니다` / 빨간 칸이 많음 | 빨간 칸 쪽으로 판을 더 가져가서 다시 찍기 |
| `판정: 부족` → 저장 안 함 | 위 안내대로 다시 찍기 (억지로 저장: `--force`) |

---

## ② 위치·방향 (폰을 놓을 때마다)

**놓기**

- 두 폰을 삼각대에 **가로로** 고정합니다. 촬영 규칙: 한 대는 정면, 한 대는 45도 옆, **골반 높이(약 1 m)**.
- 폰을 **10도쯤 아래로** 숙이면 바닥 판이 잘 보입니다 (초광각이라 사람 전신은 그래도 들어옵니다).
- ★ 이 단계부터 **삼각대를 건드리면 처음부터 다시** 해야 합니다.

**찍기** (1.5~2분)

1. 두 폰 모두 "PC 원격 대기 켜기" → 대시보드에서 **녹화 시작** (두 폰이 같은 순간에 시작).
2. 판을 가슴 앞에 들고, **판 앞면이 두 폰 사이를 보게** 합니다 (두 폰 모두 판 앞면이 보여야 함).
3. 사람이 설 자리 주변을 **천천히** 걸어 다니며 판의 높이(무릎~머리)와 위치를 바꿉니다.
   - 두 폰에서 **1~2 m** 안쪽이 좋습니다 (멀면 판이 작아서 못 찾음).
   - 자리마다 **1초씩 멈춤**. 판을 조금씩 기울여도 됩니다.
   - 60~90초.
4. 마지막에 판을 **바닥에 앞면이 위로** 가게 눕힙니다.
   - 어느 폰이든 한 대의 화면 **아래쪽**에 들어오게, 폰에서 **1~1.5 m 앞**.
   - 손을 빼고 몸이 판을 가리지 않게 비켜서서 **5초** 기다립니다.
5. 녹화 정지 → 업로드 기다림.

**계산**

```powershell
& "$env:USERPROFILE\.venv\pose2sim_gpu\Scripts\python.exe" tools\calibrate.py extrinsics <세션이름>
```

**이렇게 보이면 성공**

- `재투영 오차` **1.0 px 이하**
- `검산: 카메라로 잰 판 한 칸 23.xx mm` — 실제와 **±1% 안쪽**
- `cam01–cam02 함께 본 장면` **45개 이상**
- `바닥 판: camNN 이 x.x초 동안 봄`
- `[결과]` 의 **높이**와 **두 폰 사이 거리**를 줄자로 재서 **±3 cm** 안쪽
  (높이 = 바닥에서 폰 렌즈까지, 거리 = 두 폰 렌즈 사이)
- `판정: 좋음`, `리그 저장: ...\Pose2SimWork\rig`
- 확인 그림 `~/Pose2SimWork/rig/check_cam01.jpg`, `check_cam02.jpg`:
  **노란 격자(0.5 m 간격)가 바닥에 붙어** 보이고, 원점 축(빨강·초록·파랑)이 바닥 판 위에 있고,
  다른 폰이 화면에 보이면 그 자리에 **보라색 동그라미**가 있음

cam01, cam02 가 어느 폰인지는 도구가 영상 파일의 기기 ID 로 정해 `cameras.json` 에 씁니다.
**손으로 고치지 마세요** (폰 2대에서는 뒤바뀌어도 품질 지표에 안 나타납니다).
지금은 기기 ID 순서라 cam01 = `6DC32E3A1F59`(iOS 17.5.1), cam02 = `CFA431374C8C` 입니다.

**안 되면**

| 보이는 말 | 할 일 |
| --- | --- |
| `렌즈 특성이 없습니다` | ① 먼저 |
| `다른 촬영 설정에서 잰 것입니다` | 렌즈·해상도·fps 가 바뀌었음 → ① 다시 |
| `함께 본 장면이 N개뿐` | 판 앞면이 두 폰 모두에 보이게, 두 폰에 더 가까이 |
| `판 한 칸이 xx mm` (±2% 넘게 틀림) | 인쇄 크기 확인, `--square-mm` |
| `바닥에 눕힌 판을 찾지 못했습니다` | 리그는 써집니다(3D 됨). 바닥·수직이 조금 틀어질 수 있음. 다음엔 판을 폰에 더 가깝게, 밝게 |
| `사이드카에 치명 문제` | 시계 동기 문제 → 녹화 직전에 다시 동기되게 앱을 다시 켜고 다시 찍기 |

지금 상태 보기: `tools\calibrate.py status`

## 도구가 하는 일 (궁금할 때)

- 영상에서 판의 안쪽 꼭짓점 54개를 찾고, **판이 느리게 움직인 순간만** 씁니다.
- ① OpenCV `calibrateCamera` (왜곡 계수 k1 k2 p1 p2 k3). 서로 다른 장면을 최대 60개 골라 계산하고,
  계산에 안 쓴 장면으로 다시 검산합니다.
- ② 사이드카의 프레임 시각으로 **두 폰이 같은 순간 본 판**을 짝짓습니다 (앞뒤 프레임을 시각대로
  보간 — 리샘플러와 같은 생각). 그다음 두 카메라 자세와 장면마다의 판 자세를 함께 맞춥니다
  (번들 조정). 바닥 판으로 위쪽 방향과 높이 0 을 정합니다.
- 결과는 Pose2Sim 형식 `Calib.toml` (카메라 순서 cam01, cam02 …) + `cameras.json` + `rig_report.json`.
  이전 리그는 `~/Pose2SimWork/rig_backup/<시각>/` 으로 옮겨 둡니다.
- 설계 근거: `docs/DESIGN.md` §4.5
